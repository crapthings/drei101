# 11 视频、音频与人脸验收记录

- `/#/demo/PositionalAudio`：播放并移动声源时，音频分析数据随左右位置和距离变化；暂停可停止播放。待用耳机确认实际听感。
- `/#/demo/ScreenVideoTexture`：模拟视频流和模拟拒绝状态已验证。自动化浏览器请求真实屏幕共享时返回 `InvalidStateError`；待手动选择共享源并验证画面和停止操作。
- `/#/demo/WebcamVideoTexture`：真实摄像头画面及停止操作已验证；拒绝和重试使用模拟错误验证。
- `/#/demo/FaceControls`：样例姿态可改变相机目标；实时模式使用公开人像视频流验证了检测和相机移动，真实摄像头头部跟踪尚未验证。
- `/#/demo/FaceLandmarker`：人像样例检测到 1 张人脸、478 个关键点；空白图片检测到 0 张人脸，切换有效。
- `/#/demo/Facemesh`：样例网格显示 478 个顶点、880 个三角形，线框、调试和视线选项可切换。
